# Akshay Dilip Barmate - Interactive Marriage Profile & Biodata

Official interactive marriage profile and biodata web application for **Akshay Dilip Barmate**.

## 🌟 Highlights & Features

- **Interactive Biodata & Highlights**: Modern, elegant UI with smooth scrolling and dynamic age calculation.
- **Photo Showcase & Lightbox**: High-resolution gallery showcase with fullscreen lightbox preview.
- **Night Mode Theme**: Curated dark palette with luxury gold and royal navy accents.
- **100% Mobile Responsive**: Customized drawer menu, touch-scrolling quick navigation tabs, and fluid layouts for all devices.
- **Direct WhatsApp Integration**: 1-click instant connection to WhatsApp (+91 7756909607).
- **One-Click Biodata Copy**: Built-in instant clipboard copy formatted for WhatsApp and Email sharing.
- **Print & PDF Support**: Integrated `@media print` stylesheet for clean printing and PDF downloads.

## 🚀 Running Locally

You can run the web app using Node.js:

```bash
node server.js
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.
